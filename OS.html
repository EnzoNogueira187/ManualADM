Ordem de Serviço - OS



Para toda Guia, é gerado no minimo uma OS e no maximo quantas OS forem necessárias para a produção de um dado Pedido.
Quantas Ordens de Serviços devem ser abertas para uma Guia?
A resposta é simples, é pelo número de trabalhos que o pedido gera dentro da empresa.

Exemplos:

A - GERANDO UMA OS


O cliente Cia & Cia fez um pedido de 100.000 imagens e para produzir isto eu vou gerar uma única Ordem de Serviço, porque? Por ser um pedido que envolve um único tralho, ou seja, produzir as imagens. Neste caso, teremos uma guia com uma unica ordem de serviço.





B - GERANDO MAIS DE UMA OS


O Cliente Banco Ltda fez um pedido de 50.000 talões de cheque e para produzir isto eu vou gerar 3 Ordens de Serviços, porque?
Por ser um pedido que envolve mais de um tipo de trabalho, ou seja, 01 trabalho para gerar as capas, outro para gerar as folhas e outro para gerar as contra capas.
Neste caso, teremos uma guia com 3 ordens de serviços.
